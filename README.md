# Project 2: Queueing System Simulation

A C++ project for Data Structures and Algorithms II that compares analytical queueing model results with simulation results.

The program reads input data from test files, computes queueing statistics using an analytical model and a simulator, and prints the results to the console.

Please refer to **UsersManual.pdf** in the root of this project for more detailed information and how to run the program.
